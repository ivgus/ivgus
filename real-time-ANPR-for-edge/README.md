# ML-модель детекции и распознавания российскийх автомобильных номеров
Проект представляет собой систему компьютерного зрения на основе свёрточных нейронных сетей для решения ANPR задачи в реальном времени.
Модули: детектирование номера с помощью предобученной yolov8n, распознавание номера с помощью собственной реализации архитектуры LPRNet.
Модель была оптимизирована для ускорения работы и уменьшения требуемой памяти. Распознавание обучалось на CTCLoss.

Тестирование распознавания: Total Samples 2845, Full Accuracy 0.7135 (т.е. 2030 из 2845), Character Accuracy: 0.8375

Обучение моделей проходило на базе открытых датасетов с номерами автомобилей.

Технологии: Python, Numpy, Pytorch, OpenCV, Ultralytics, json
