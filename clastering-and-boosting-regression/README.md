# Определение средней стоимости медицинского обсуживания пациента с помощью кластеризации и градиентного бустинга
Программа определения средней стоимости медицинских услуг в зависимости от характеристик пациента (возраст, пол, индекс массы тела, количество детей, курение, регион проживания) с использованием кластеризации и градиентного бустинга.
Библиатека CatBoost реализует модель градиентного бустинга для регрессии и частичную предобработку данных (стандартизацию). Проведён статистический анализ данных, графиков зависимостей. С помощью кластеризации алгоритмом KMeans (методом локтя найдено оптимальное количество кластеров) был добавлен синтетический признак - принадлежность к кластеру.

Ошибка MAE 2404.54$.
Точность модели R^2 Score: 0.8811

Технологии: Python, Numpy, Pandas, Scikit-learn, Matplotlib, Seaborn, CatBoost.
