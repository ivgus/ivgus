# Fine Tuning модели анализа тональности текстовых отзывов
Программа для определения тональности текстового отзыва на русском языке из разных сфер с использованием дообученной модели построения эмбеддингов из семейства BERT (RuBERT).
Проведена фильтрация и токенизация данных. Дообучение проводилось с помощью библиотеки transformers.

Ошибка классификации Crossentropy 0.2816.
Точность модели accuracy 0.78.

Технологии: Python, Numpy, Pandas, PyTorch, Scikit-learn, Matplotlib, Transformers, Datasets (Hugging Face).
