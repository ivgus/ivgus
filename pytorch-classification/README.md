# Определение наличия заболевания сердца на PyTorch
Программа для определения наличия или отсутствия сердечно-сосудистых заболеваний в зависимости от характеристик пациента (возраст, пол, тип боли в груди, уровень холестерина, кровеносное давление, уровень сахара, электрокардиография, максимальная частота сердечных сокращений, уровень подавленности при нагрузке и покое, укрупнение сосудов, флуороскопия) с использованием нейронных сетей.
Проведена MinMax нормализация. Метод оптимизации Adam. Созданы класс и методы для работы модели и обработки данных с их подачей. 

Ошибка классификации Binary Crossentropy 0.1401.
Точность модели accuracy 0.9756.

Технологии: Python, Numpy, Pandas, PyTorch, Scikit-learn.
